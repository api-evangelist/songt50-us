# sapjilcoding

> sapjilcoding (삽질코딩, GitHub SongT-50) is a Korean independent maker that publishes two live A2A agents on songt50.us — the Korean Public Data Agent and the Korean News Agent — and four open-source MCP servers (Korean Public Data, Korean News Hub, Korean Stock Market Data, Korean Agriculture Market Data) listed in the official MCP registry. All surfaces are read-only, anonymous and free. No OpenAPI, GraphQL, AsyncAPI, gRPC or SOAP contract is published. This file was generated by API Evangelist from the provider's published artifacts; it is not provider-authored.

## A2A agents (live 2026-09-19, JSON-RPC 2.0, anonymous)

- [Korean Public Data Agent card](https://publicdata-agent.songt50.us/.well-known/agent-card.json): weather, air quality, apartment prices, Bank of Korea statistics, business registration checks; JSON-RPC endpoint https://publicdata-agent.songt50.us (POST only)
- [Korean News Agent card](https://news-agent.songt50.us/.well-known/agent-card.json): Korean news by category, global tech news, keyword search, trending, daily briefing; JSON-RPC endpoint https://news-agent.songt50.us (POST only)
- Both cards also served at the legacy /.well-known/agent.json; protocolVersion 0.3.0, preferredTransport JSONRPC, streaming and push notifications false

## MCP servers (official registry namespace io.github.SongT-50; hosted endpoints suspended 2026-09-19, HTTP 503)

- [Korean Public Data MCP](https://github.com/SongT-50/korean-public-data-mcp): remote https://korean-public-data-mcp.onrender.com/mcp; tools check_business_registration, get_real_estate_trades, get_weather_forecast, get_air_quality, get_economic_stats, list_supported_options
- [Korean News Hub MCP](https://github.com/SongT-50/korean-news-mcp): remote https://korean-news-mcp.onrender.com/mcp; tools korean_news, tech_news, news_search, trending, read_article, daily_briefing; no API key
- [Korean Stock Market MCP](https://github.com/SongT-50/korean-stock-mcp): remote https://korean-stock-mcp.onrender.com/mcp; tools get_stock_price, search_stock, get_market_index, get_price_trend, get_dividend_info, compare_stocks, get_popular_stocks
- [Korean Agriculture Market MCP](https://github.com/SongT-50/korean-agriculture-mcp): remote https://korean-agriculture-mcp.onrender.com/mcp; tools get_realtime_auction, search_product_price, compare_market_prices, get_price_trend, get_market_list, get_auction_summary
- Local run for any of them: git clone the repository, pip install -r requirements.txt, python server.py (stdio); the data servers need your own data.go.kr and ECOS keys when self-hosted
- [MCP registry listing](https://registry.modelcontextprotocol.io/v0/servers?search=io.github.SongT-50)
